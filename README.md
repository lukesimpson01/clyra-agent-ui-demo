# Clyra Agent UI Demo

A self-contained light-themed UI showcase for agent actions and response states: thinking, search, file diffs, browser preview, document and presentation editors, music, and a compact task list.

## Run locally
```bash
npm run dev
```

Open http://localhost:5173 .

The demo is a visual simulation; it does not call external services or replace an existing chat's backend, composer, or message bubbles.

See `AGENTS.md` and `INTEGRATION_GUIDE.md` for integration guidance.
